# Week 1 — Five Cybersecurity Case Studies

## Objective

The objective of Week 1 is to identify five high-level cybersecurity problems that have:

* A clearly defined cybersecurity challenge
* A technically meaningful proposed solution
* Potential for cloud or cloud-connected deployment
* A measurable technical outcome
* Scope for research and prototype development
* Potential novelty requiring further prior-art and patent investigation

These five candidates will be evaluated during Week 2 before selecting the final two projects.

## Case Study Selection

| ID    | Case Study                           | Primary Domain           | Deployment Model     |
| ----- | ------------------------------------ | ------------------------ | -------------------- |
| CS-01 | Cross-Tenant Ransomware Containment  | Cloud Security           | Cloud                |
| CS-02 | Zero-Downtime Post-Quantum Migration | Cryptographic Security   | Multi-Cloud          |
| CS-03 | Real-Time Deepfake Detection         | Communication Security   | Cloud Media Pipeline |
| CS-04 | Cumulative API Attack Detection      | Application/API Security | Cloud-Native         |
| CS-05 | Cyber-Physical IoT/OT Isolation      | IoT/OT Security          | Edge + Cloud         |

## Common Research Direction

The five proposals focus on cybersecurity systems that do more than simply detect threats.

The proposed systems aim to follow a broader security cycle:

```text
Monitor
   ↓
Analyze
   ↓
Understand
   ↓
Decide
   ↓
Automatically Enforce
   ↓
Audit
```

The exact detection, analysis, and enforcement mechanisms will be refined after literature, prior-art, and patent analysis.

## Important Status Note

These are proposal-stage academic case studies.

No production deployment or measured experimental results are claimed at this stage. Target outcomes will be validated through future prototype development and controlled testing.

Patentability is also not claimed at this stage. The proposed technical contributions will undergo prior-art and patent analysis during Week 2.
