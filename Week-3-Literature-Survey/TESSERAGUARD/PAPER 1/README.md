# Paper 1 — Authorization Propagation in Multi-Agent AI Systems: Identity Governance as Infrastructure

**Project:** TesseraGuard — Aggregation-Aware API Threat Detection & Enforcement Gateway

**Source:** arXiv, 2026

**Paper:** https://arxiv.org/abs/2605.05440

## What the Existing Solution Is

A formal study of how authorization should work when AI agents delegate tasks to other agents in a chain.

It names and defines **"aggregation inference"** — the situation where several individually-authorized actions, combined, reveal or enable something none of them was individually authorized for — and shows this is largely unsolved for multi-agent systems.

## Which Part Is Used in the Proposed Solution

The **problem definition itself**.

TesseraGuard borrows the paper's formal framing of aggregation inference as the target problem, rather than any specific algorithm from the paper.

The paper does not propose a working solution; it defines the gap.

## How It Is Useful

It gives TesseraGuard a citable, academically-recognized name and definition for its core problem, and independent confirmation that this is a genuine, currently-unsolved research gap — not just an assumed opportunity.

TesseraGuard's contribution is extending this named problem from multi-agent AI delegation into general cloud API security.
