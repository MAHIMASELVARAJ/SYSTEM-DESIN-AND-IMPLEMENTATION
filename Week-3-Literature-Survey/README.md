# Week 3 – Literature Survey

## Objective

The objective of Week 3 is to conduct a literature survey for the two shortlisted cybersecurity and digital trust projects.

The selected reference papers are limited to recent research from 2024–2026 and are selected based on their direct technical relevance to the proposed systems.

The survey focuses on identifying:

- Existing technologies
- Existing system workflows
- Algorithms and security mechanisms
- Components that can be implemented or adapted
- Limitations of existing approaches
- Research gaps
- Relevance to the proposed system

## Selected Projects

### 1. AgentGuard
Purpose-Bound Security Firewall for Autonomous AI Agents

### 2. ProofPulse
Stateful Action-Level Dynamic Trust Verification

## Literature Survey Structure

Each project contains five recent reference papers.

For every paper, the analysis includes:

1. Paper details
2. Problem addressed
3. Existing system
4. Existing technologies/methods
5. Important workflow
6. Component adopted/adapted for the proposed system
7. Proposed-system module where it will be used
8. Limitations of the existing work
9. Research gap
10. Relevance to the proposed project
11. Reference/download information
