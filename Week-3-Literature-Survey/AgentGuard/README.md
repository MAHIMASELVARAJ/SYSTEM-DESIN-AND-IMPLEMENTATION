# AgentGuard – Literature Survey

## Proposed Project

**AgentGuard: Purpose-Bound Security Firewall for Autonomous AI Agents**

## Objective

AgentGuard is proposed as a runtime security layer between autonomous AI agents and the tools, APIs, databases and external resources they access.

The system aims to determine whether an agent's requested action is consistent with the user's original purpose, delegated permissions, resource scope, data sensitivity and execution history.

## Literature Survey

Five recent papers have been selected to provide technical foundations for the proposed architecture.

| Paper | Year | Main Technology Used |
|---|---:|---|
| AgentDojo | 2024 | Agent security testing |
| The Task Shield | 2025 | Task/intent alignment |
| Authenticated Delegation and Authorized AI Agents | 2025 | Agent identity and delegation |
| Towards Verifiably Safe Tool Use | 2026 | Capability and tool-sequence security |
| AgentSecBench | 2026 | Agent security evaluation |

## Research Direction

The proposed system will investigate the integration of intent alignment, authenticated delegation, capability control, data-flow monitoring and tool-sequence analysis into a purpose-bound runtime enforcement architecture.

The final novelty and patentability of the proposed contribution will require separate prior-art and patent analysis.
