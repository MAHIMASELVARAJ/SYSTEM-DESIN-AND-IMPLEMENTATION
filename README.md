# Cybersecurity & Digital Trust – Case Studies

## Week 1 Project Exploration

This repository contains five proposed real-world case studies
focused on Cybersecurity and Digital Trust.

The objective is to identify practical, high-impact problems that
can be addressed through cloud-based technology and potentially
developed into a novel technical solution.

## Case Studies

| No. | Project | Focus |
|---|---|---|
| 1 | ProofPulse | Dynamic trust verification |
| 2 | AgentGuard | Security for autonomous AI agents |
| 3 | DeepShield | Deepfake transaction protection |
| 4 | DataLeak Sentinel | Predictive data exposure prevention |
| 5 | TrustBridge | Digital credential trust evaluation |

## Objective

The five case studies will be evaluated based on:

- Real-world relevance
- Cybersecurity impact
- Digital trust contribution
- Technical feasibility
- Cloud deployment feasibility
- Innovation potential
- Prior-art landscape
- Potential for developing a differentiated technical mechanism

## Important Note

The proposed concepts are innovation candidates and are not
claimed to be automatically patentable. A detailed prior-art
and patentability analysis will be performed before selecting
the final project.

## Selection Process

Five case studies → Evaluation → Shortlist two → Faculty selection
→ Detailed design thinking → Prototype → Cloud deployment
